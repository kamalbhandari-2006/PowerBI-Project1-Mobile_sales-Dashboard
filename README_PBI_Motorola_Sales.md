# Motorola Sales Dashboard --- Power BI

## Project Overview

The **Motorola Sales Dashboard** is an interactive Power BI report
designed to analyze mobile phone sales performance. It brings key sales
metrics and visual insights together in one place, helping users explore
sales, quantities sold, transactions, customer ratings, payment methods,
mobile models, and city-level performance.

## Dashboard Highlights

-   **Key Performance Indicators (KPIs):**
    -   Total Sales
    -   Total Quantity Sold
    -   Total Transactions
    -   Average Sales Value
-   **Interactive Filters:**
    -   Mobile Model
    -   Payment Method
    -   Brand
    -   Day Name
    -   Month selector
-   **Sales by City:** Map visualization showing sales distribution
    across cities.
-   **Monthly Units Sold:** Trend chart comparing units sold across the
    months.
-   **Customer Ratings:** Funnel visualization summarizing customer
    rating counts.
-   **Transactions by Payment Method:** Breakdown of transactions across
    UPI, debit card, credit card, and cash.
-   **Brand Performance:** Table comparing total sales, quantity sold,
    and transactions by brand.
-   **Sales by Mobile Model:** Comparison of sales across selected
    mobile models.
-   **Sales by Day Name:** Visualization of sales performance across the
    days of the week.

## Tools Used

-   **Microsoft Power BI Desktop** --- dashboard development and
    visualization
-   **Power Query** --- data preparation and transformation, where
    applicable
-   **DAX** --- measures and calculations, where applicable

## Interactive Features

The dashboard includes slicers and visual interactions so users can
filter the report and explore how sales performance changes by month,
brand, mobile model, payment method, and day of the week.

## How to View the Project

1.  Download or clone this repository.
2.  Open the `.pbix` file using **Microsoft Power BI Desktop**.
3.  Refresh the data if the original data source is available and Power
    BI requests it.
4.  Use the slicers and visualizations to explore the report.

> **Note:** The Power BI report may require the original dataset or a
> valid data-source path to refresh. If the dataset is not included in
> this repository, the report can still be shared as a project file, but
> refreshing may require reconnecting the source.
